# Phase 1 Data Model: The Evaluation Harness

**Feature**: `003-eval-harness` | **Date**: 2026-09-12 | **Plan**: [plan.md](./plan.md)

Three groups: **dataset entities** (what is loaded, never committed), **evaluation entities** (what
a run produces), and **fixture entities** (committed goldens). Core types are `xtriever-core`'s and
unchanged.

---

## Dataset entities

### `DatasetManifest` (`reference/datasets/beir-manifest.json`, committed)

| field | type | rules |
|---|---|---|
| `datasets[name]` | map | exactly `scifact`, `nfcorpus`, `fiqa` |
| `.url` | string | the pinned source URL |
| `.archive.bytes` / `.archive.sha256` | u64 / hex | research D1 table; verified by the fetch script |
| `.files[path]` | map | `corpus.jsonl`, `queries.jsonl`, `qrels/test.tsv` — `bytes`, `sha256`, `lines` from research D1; **verified by the Rust loader on every load** (FR-006) |
| `.counts` | object | `documents`, `queries`, `judged_queries`, `judgement_pairs` — research D1 counts, asserted after parsing (FR-009) |

A hash mismatch is `Error::Corrupt`-style hard failure naming the file and both hashes (FR-007);
loading never proceeds past it.

### `Corpus`

| field | type | rules |
|---|---|---|
| `ids` | `Vec<String>` | BEIR `_id`, in file order; index = internal `DocId(u32)` — the only id → external map, held by the harness, never given to a backend (FR-014) |
| `titles`, `texts` | `Vec<String>` | empty title kept as empty string; the config decides whether an empty field is added |

### `QuerySet`

| field | type | rules |
|---|---|---|
| `queries` | `Vec<(String, String)>` | `(_id, text)` in file order; all queries are loaded, only judged ones are run |

### `Qrels`

| field | type | rules |
|---|---|---|
| `grades` | `BTreeMap<String, BTreeMap<String, u32>>` | query id → document id → grade; header line skipped, `\r` stripped (research D2) |
| relevant set per query | derived | grades > 0 |
| `dangling` | `{ queries: Vec<String>, documents: Vec<String> }` | judged ids missing from the query set / corpus — reported, not fatal (FR-010); 0 for all three today |

## Evaluation entities

### `EvalConfig`

| field | type | rules |
|---|---|---|
| `name` | string | `lexical-baseline-v1` is the only one defined; others are informational (FR-016) |
| `fields` | list of `{ name, analyzer, boost, indexed_from: "title" \| "text" }` | builds the core `Schema`; `title` boost 2.0, `text` 1.0, both `standard_en` |
| `omit_empty_fields` | bool | `true`: an empty BEIR title adds no field (FiQA) |
| `query` | enum | `MatchAll` ⇒ `LexicalQuery::Match(None, text)` |
| `k` | usize | 100; must be ≥ 100 (FR-012) |

### `Run`

| field | type | rules |
|---|---|---|
| `config` | `EvalConfig` | |
| `dataset` | name + manifest hashes | |
| `results` | `BTreeMap<String, Vec<String>>` | judged query id → ordered external doc ids, ≤ `k`; **order is the retriever's** and is never re-sorted (research D4) |
| `dropped_identical` | u32 | results removed because doc id == query id (BEIR wrapper rule, research D3) |
| `unjudged_queries` | u32 | queries run but not judged — 0 for this harness by construction |

Exported as JSONL (`{"query_id": …, "doc_ids": [...]}` per line) for `--verify-run`.

### `QueryMetrics` / `EvalReport`

| field | type | rules |
|---|---|---|
| per query `ndcg_10`, `recall_100` | f64 | research D3 rules |
| `mean_ndcg_10`, `mean_recall_100` | f64 | sum in ascending query-id order over `scored_queries`, ÷ `scored_queries` (FR-004) |
| `mean_*_beir_rounded` | f64 | `round(·, 5)`, BEIR's presentation |
| `scored_queries` | u32 | judged queries with a (possibly empty) result list |
| `no_relevant_queries` | u32 | judged queries with no grade > 0 (counted as 0.0) |
| `dropped_identical` | u32 | from `Run` |
| `lexical_commit`, `harness_commit` | 40-hex | `94ddbe67f926badf962b93e8bd29d687e300189a` and `git rev-parse HEAD` at run time |
| `dataset_hashes` | map | every manifest hash used |
| `observations` | optional | FiQA only: `index_dir_bytes`, `peak_rss_bytes`, `method` (FR-018) |

### `Delta`

| field | rules |
|---|---|
| per dataset × metric | `before`, `after`, `abs = after − before`, `rel = abs / before` |
| `adr_trigger` | true iff `after.ndcg_10 < before.ndcg_10` on ≥ 2 of the 3 datasets (FR-022) |
| smoke verdict | FAIL iff either SciFact metric is lower than the baseline by more than 0 (FR-024) |

## Fixture entities (`reference/fixtures/003/`, committed)

### `MetricGoldens` (`metrics.json`)

Generated by `reference/gen_003_fixtures.py` with `pytrec_eval 0.5`. Each case: `name`, `qrels`,
`run` (ordered ids per query), and the reference's per-query and mean `ndcg_10` / `recall_100`.
Cases, one per FR-002 clause at minimum:

| case | what it pins |
|---|---|
| `graded` | linear gain with grades 1 and 2 (NFCorpus has grade 2) |
| `no_relevant` | judged query with all grades 0 ⇒ 0.0, counted |
| `fewer_than_cutoff` | 3 results for a query with 3 relevant |
| `empty_results` | judged query with an empty list ⇒ 0.0, counted |
| `unjudged_query` | a run query absent from qrels ⇒ ignored |
| `not_retrieved` | a judged query absent from the run ⇒ excluded from the mean |
| `duplicate_ids` | a result id repeated — trec_eval counts a doc once; the harness must match |
| `ties_at_cutoff` | equal "scores" straddling rank 10 and rank 100 — order given, not re-sorted |
| `identical_ids` | query id equals a doc id ⇒ dropped before scoring |
| `grade_zero` | explicit 0 grade is non-relevant and not in the recall denominator |
| `big_mean` | 50 random queries, mean in fixed order |

`manifest.json` records SHA-256 per file; `tests/fixtures_valid.rs` asserts them.

## State transitions

```
manifest ──fetch-beir.sh──► cache verified ──load (re-verify)──► Dataset
Dataset + EvalConfig ──build──► Schema + Documents + id map ──index (example)──► LexicalIndex
LexicalIndex + QuerySet ──run──► Run ──score(Qrels)──► EvalReport ──commit──► baseline
EvalReport × 2 ──delta──► Delta ──smoke──► PASS / FAIL
```
