# ADR-0012: The re-rank stage interpolates by default; the descriptor records the mode

- **Status**: Accepted — 2026-09-16
- **Date**: 2026-09-16
- **Deciders**: mirth (repository owner) — Feature 014's decision rule (option B), Feature 015's
  Q1 (option A)
- **Spec**: [015-rerank-interpolation](../../specs/015-rerank-interpolation/spec.md); the
  measurement in [014-rerank-depth-study](../../specs/014-rerank-depth-study/report.md)
- **Trigger**: Principle V — the on-disk descriptor gains a key and the pipeline's default
  ranking behaviour changes; Principle II — a ranking change with its deltas on record

## Context

Since Feature 006 the re-rank stage ordered the first `rerank_depth` fused candidates by the
cross-encoder's score alone ("replace"), then the rest in fused order. Feature 013's better
lexical list exposed the cost: on SciFact the re-ranked list landed below the un-re-ranked one
at every depth (ADR-0011), and the three-set mean of `hybrid-rerank-v2` (0.4768) fell below
`hybrid-baseline-v2` (0.4790). Feature 014 measured, under a rule fixed before any run, twenty
alternatives derived exactly from one depth-50 run per dataset. The winner:

| configuration | SciFact | NFCorpus | FiQA | mean |
|---|---|---|---|---|
| depth 0 (`hybrid-baseline-v2`) | 0.7144 | 0.3535 | 0.3692 | 0.4790 |
| replace, depth 20 (the default until now) | 0.6954 | 0.3609 | 0.3742 | 0.4768 |
| **interpolate α 0.5, depth 20** | **0.7207** | **0.3622** | **0.3910** | **0.4913** |

Interpolate: within the scored head, `(1 − α)·minmax(fused score) + α·minmax(cross-encoder
score)`, both min-max normalised over the head, ties by fused rank; the rest in fused order.
It is above depth 0 on every dataset (+0.6 / +0.9 / +2.2 points), +1.45 mean points over
replace at the same twenty cross-encoder calls per query; α 0.25–0.75 all qualify (a plateau,
not a fitted optimum); depth 50 adds nothing over 20.

## Decision

1. **The interpolating rule at α 0.5 is the pipeline's default** (`RerankMode::Interpolate {
   alpha: 0.5 }`, `HybridConfig::new`); the replace rule remains under `RerankMode::Replace`,
   bit-identical to Feature 006 (its goldens are unchanged and still checked).
2. **The descriptor records the mode** (`rerank_mode`, after `rerank_depth`). **A descriptor
   without the key reads as the default.** The format version stays 2: the key has a default,
   every earlier index opens, and — deliberately — its re-ranked heads change order on upgrade.
   The mode is a search-time rule over the same passages, postings and vectors, not a property
   of what was indexed; the shipped Wikipedia index and the 007 fixture index therefore gain the
   new order without a rebuild.
3. **Reproducibility**: `SearchOptions::rerank_mode = Some(Replace)` (and its FFI / Python
   equivalents) reproduces every 006–014 result on any index; the harness's `hybrid-rerank-v1`
   and `-v2` select `Replace` and reproduce their baselines. `hybrid-rerank-v3` is the re-rank
   baseline from here on and reproduces Feature 014's `lin-0.5-d20` cells list for list.
4. **Explain** reports the combined score (`rerank_combined`, feature `rerank.combined`) so the
   ordering of every re-ranked hit is inspectable; the hit's public `score` keeps its meaning
   (the fused score).
5. **The boundary goldens** (`swift/Xtriever/Tests/Fixtures/expected.json`) are regenerated by
   their generator: the un-re-ranked responses are byte-identical; seven of the eight
   re-ranked heads changed; `info` gains `rerank_mode`.

## Consequences

- Callers on existing indexes see the new head order after upgrading; those who need the old
  order pass the override or record `Replace` at build.
- The 013 SciFact regression recorded in ADR-0011 is closed: the best re-ranked SciFact number
  is now above the un-re-ranked one.
- The LTR stage, when trained, has an eighth pipeline feature available.
- Revisit when: the cross-encoder is re-pinned or replaced; α is tuned on new evidence (it is
  a recorded value, not a constant); the fused signal changes (a sparse stage) — the rule's
  normalisation is per head, so a new fused scale needs no change, but the measurement does.
